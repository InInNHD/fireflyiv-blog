# 性能基线

目标页面：首页、文章列表、音乐、相册。用户体验目标为 LCP ≤ 2.5 秒、CLS ≤ 0.1、INP ≤ 200 毫秒；上线后应以 Umami 或浏览器现场数据为准。

构建后执行：

```bash
npm run check:performance
```

当前静态构建基线（2026-09-02）：最大 JS chunk 222.6 KiB、全部 JS 795.6 KiB、全部 CSS 86.6 KiB。CI 阈值保留约 10% 余量：250 KiB、900 KiB、100 KiB。该检查用于阻止明显的资源膨胀，不替代真实网络上的 Web Vitals。

站内封面、相册和音乐资源使用一天浏览器缓存与七天后台重新验证；`/_next/static` 继续由 Next.js 使用内容哈希和长期缓存。首页不再渲染空内容模块，音频保持 `preload=none`，统计脚本异步加载。
